# Aetheron: O Reino Caido

Modpack de fantasia medieval epica (NeoForge 1.21.1) com historia e quests
interligadas em portugues (PT-BR), dimensoes (Aether, Twilight Forest,
Undergarden, Deeper & Darker), boss fights, magia, dungeons e o shader
Aetheron (RTX 5070 ready).

## Como instalar

### Opcao 1 - Modrinth App (recomendado)
1. Baixe o Modrinth App: https://modrinth.com/app
2. Crie uma instancia Minecraft 1.21.1 + NeoForge 21.1.267
3. Adicione o modpack local (arquivo Aetheron-Reino-Caido.zip)
4. Rode o perfil "Aetheron: O Reino Caido"

### Opcao 2 - Manual
1. Instale o NeoForge 21.1.267 em uma pasta de instancia nova
2. Copie o conteudo de mods/, config/, shaderpacks/, options.txt para a pasta
3. Inicie o launcher e selecione o perfil

### Opcao 3 - packwiz
```powershell
packwiz install https://github.com/SantosFktt/Aetheron-Reino-Caido
```

## Mods principais
- **Quests**: FTB Quests, FTB Teams, FTB Library (quests em equipe)
- **Dimensoes**: The Aether, Twilight Forest, The Undergarden, Deeper & Darker
- **Dungeons**: When Dungeons Arise, YUNG's, Dungeons & Taverns, Cataclysm
- **Bosses**: L_Ender's Cataclysm, Mowzie's Mobs, Born in Chaos
- **Magia**: Iron's Spells 'n Spellbooks, Ars Nouveau, Spell Engine
- **Performance**: Sodium, Iris, ModernFix, Lithium, FerriteCore, ImmediatelyFast
- **Shader**: Aetheron v1.2.0 (PT-BR, nuvens volumetricas, TAA, bloom)

## Hardware recomendado
- RTX 5070 / equivalente
- Ryzen 7 9800X3D / equivalente
- 16GB+ RAM (alocado 8GB para o jogo)
